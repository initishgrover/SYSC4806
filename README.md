# AddressBook App

**Student:** Nitish Grover

## Project Description

This project is a Spring Boot AddressBook application. It allows address books to contain buddies with names, phone numbers, and addresses.

The application uses Spring Boot, Spring Data JPA, Thymeleaf, and an H2 database. It includes HTTP endpoints for creating address books and buddies, along with a web page for viewing address book details.
